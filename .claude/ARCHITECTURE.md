# Architecture — SpatialConverter32
> Auto-generated by Claude. Updated: 2026-06-12
> Type: fullstack (tool + viewer web)

Converte ambienti **Spatial.io + Unity** in viewer web **Three.js + WebXR**.
Piattaforma "redazione" multi-laboratorio: login, progetti su R2, editor scena, bundle scaricabile.

---

## Stack
- **Runtime**: Node ≥18 (server), Python 3.x + Blender (pipeline conversione), C# (Unity Editor scripts)
- **Framework**: Express 4 (server), Three.js + WebXR (viewer, no build step — CDN)
- **DB**: nessuno — progetti = JSON in `_projects/<slug>.json` su R2
- **Storage**: Cloudflare R2 (S3-compatible, bucket `immersivelab-assets`)
- **Auth**: password redazione unica (`EDITOR_PASSWORD`) → cookie JWT
- **Deploy**: Railway (Nixpacks, `npm start`)

## Main flows
- **Auth redazione**: `POST /api/login` (password) → `auth.js checkPassword` → JWT cookie `sct`
- **Progetti CRUD**: `/api/projects` → `store.js` → R2 (`_projects/<slug>.json`)
- **Viewer/Editor**: `GET /?project=<slug>` → `viewer/index.html` (engine) carica asset da R2
- **Upload modello**: `POST /api/projects/:slug/upload` → R2 `<prefix>/gltfModels/` (solo `.glb`) + rigenera `models.json`
- **Upload oggetto menu+**: `POST /api/projects/:slug/asset` → R2 `<prefix>/objects/` (img/PDF/MP4/360/GLB)
- **Download bundle**: `GET /api/projects/:slug/download` → ZIP (engine + scene-config + asset R2)
- **Pipeline conversione (offline)**: FBX (Unity) → `tools/legacy/blender/merge_and_export.py` (Blender) → `environment.glb`
- **Import feature Spatial**: Unity exporter (`unity/*.cs`) → `tools/parse_*.js` → quest/azioni/quiz nel viewer

- 2026-06: viewer senza build step — Three.js da CDN, un solo `index.html` come engine
- 2026-06: auth minimale a password unica redazione (non multi-utente)

- 2026-06: un GLB = un oggetto unico; `.gltf` multi-file bloccato all'upload (scena rotta)

- 2026-06: storage multi-progetto — `MODELS_DIR`/`content/` per progetti ≠32; `INFRASTRUTTURA.md` fonte autorevole
